Как изменились зависимостиHow dependencies changed

  • S1 запускает ROS до окончания всей математики и аппаратных курсов. S2 добавляет TF/модель и аппаратные интерфейсы позже. Это один M12, разделённый на30+40ч.S1 starts ROS before all mathematics/hardware courses finish. S2 later adds TF/model and hardware interfaces. It is one M12 split into30+40h.
  • D1=40ч статики/опор выполняется до L1; D2=58ч динамики/валидации использует готовый стенд позже. Полный M09 не является входным барьером для ноги.D1=40h statics/support checks precede L1; D2=58h dynamics/validation uses the completed rig later. The full M09 is not an entry barrier for the leg.
  • M11 с практической IMU-оценкой идёт перед внешним контроллером M10. LQR/QP из прежнего M11 находятся в развитии.M11 practical IMU estimation precedes M10 outer control. The old M11 LQR/QP material moves to development.
  • M19 содержит одну модель на4/6ног, а M13 — стенд одной ноги. Модель не оплачивается повторно в M22/M23.M19 contains one four/six-leg model, while M13 covers the single-leg rig. The model is not counted again in M22/M23.
  • M14 теперь классическое зрение и геометрия фиксированной камеры; M18 после него использует тот же набор эпизодов для ML. Поэтому прежняя зависимость CNN до/после M18 заменена выбранной последовательностью.M14 now covers classical vision and fixed-camera geometry; M18 follows it using the same episodes for ML. The former CNN prerequisite ordering is replaced by this selected sequence.
